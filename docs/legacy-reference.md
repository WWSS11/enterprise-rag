# 旧项目能力取舍

| 旧项目思路 | 新设计 |
| --- | --- |
| 多格式文档解析 | 保留并补齐 XML、PPTX、旧 XLS，提取页码/Sheet/Slide 元数据 |
| SHA-256 去重 | 保留，但从租户级改为知识库级，允许相同内容用于不同授权域 |
| 启动时自动扫描目录 | 移除；改为受控 root alias + Celery 异步扫描 |
| 批量 embedding、批次失败逐条回退 | 保留；默认任何缺块都不发布新版本 |
| 指代问题改写 | 保留；只对短问题和含指代表达的问题调用 LLM，降低成本与漂移 |
| Top20、阈值过滤、Top5 rerank | 保留为可配置检索工作流 |
| 真正 token SSE | 保留；由 LangGraph custom stream 直接传递模型 token |
| Redis 会话 | Redis 只作缓存，PostgreSQL 保存事实消息，避免缓存丢失即丢会话 |
| Redisson 用户/全局限流 | 改为 Redis Lua 原子用户+租户令牌桶和每日配额，返回真实 HTTP 429 |
| 飞书递归与增量同步 | 保留，统一进入版本化异步入库链路，并加入分布式同步锁 |
| 更新前先删除旧向量 | 拒绝；新版本发布成功后再清理旧版本 |
| 业务错误统一 HTTP 200 | 拒绝；使用标准 HTTP 状态和 RFC Problem Details |
| 直接信任 `X-Forwarded-For` | 拒绝；身份只允许来自受保护网关头，并可校验共享 secret |
| 没有真实测试但 README 声称有 | 拒绝；当前测试、静态检查和 Docker 端到端结果均实际执行 |

新项目因此是“能力继承、实现重做”，而不是语言迁移或接口兼容层。
