# T14 数据治理与模型供应商审查 — 2026-08-04

## 数据分类与准入

| 等级 | 示例 | 外部模型规则 |
| --- | --- | --- |
| Public | 已公开法规、公开产品资料 | 来源与版权确认后可使用 |
| Internal-sanitized | 去除身份和商业秘密的内部制度 | 供应商审查为 `approved` 后才可使用 |
| Confidential | 合同、报价、源数据、未公开经营信息 | 默认禁止，必须单独审批和最小化 |
| Restricted | 身份证件、生物识别、健康、金融账户、认证凭据、国家秘密 | 禁止进入当前外部模型链路 |

进入系统前由数据负责人完成不可逆脱敏。姓名、手机号、邮箱、证件号、详细地址、账户号、设备
标识和可组合重识别字段必须删除或替换；凭据、Token、私钥和密码不得以任何形式上传。评测包
必须记录分类、审批引用和供应商审查结论，`blocked` 数据不能导入。

## 访问与审计

- 身份只来自验证后的 OIDC claims；租户由 Token 固定，客户端不能切换。
- `restricted` 知识库按用户或群组授予 reader/editor/owner；管理员权限仍受租户边界限制。
- 文档上传、重新入库、删除、知识库成员变化、聊天完成、评测运行、指标重算和质量门禁均写入
  审计日志；日志只记录资源 ID、动作和必要诊断，不记录 Token、密钥或完整文档正文。
- 数据导出、法律保留和大批量删除目前没有产品接口，必须由数据负责人建立审批工单并记录执行
  人、目标 ID、时间和结果。

## 保留与删除策略

| 数据 | 默认保留 | 删除触发与方式 |
| --- | --- | --- |
| 上传原文、分块和向量 | 知识库处于业务使用期 | 文档删除任务同步删除原文、分块和对应向量 |
| 已归档知识库元数据 | 365 天 | 审计确认无活动任务和法律保留后再物理清理 |
| 会话与消息 | 最后活动后 90 天 | 先归档；物理清理功能实现前由数据负责人登记待清理清单 |
| 评测集、运行和证据 | 基线失效后 180 天 | 保留冻结报告后按评测集级联清理 |
| 入库任务记录 | 完成后 180 天 | 保留失败恢复窗口后清理 |
| 审计日志 | 365 天 | 安全或法律保留可延长；到期后最小化删除 |

当前应用已经实现文档及向量的一致性删除、知识库/会话归档和审计记录。会话、评测、任务与审计
日志的自动到期物理清理尚未实现，不能声称系统会自动满足上述期限；在产品功能补齐前由数据
负责人按月审查并登记待清理对象。

## 当前模型链路审查

| 环节 | 当前服务 | 公开条款结论 | 内部数据结论 |
| --- | --- | --- | --- |
| Embedding | SiliconFlow | 平台协议称交互数据不保存、不披露；隐私政策说明用户信息在境内保存，并提供删除/撤回权利 | 仍需企业合同、模型第三方链路和删除 SLA 审核 |
| Rerank | SiliconFlow | 同上 | 仍需正式审批 |
| Chat | 当前配置使用非官方中转域名 | 未找到可核验的数据使用、训练、留存、跨境和删除条款 | `blocked`，禁止发送内部资料 |

审查依据：

- [SiliconFlow 平台使用协议（更新日期 2026-05-22）](https://api-docs.siliconflow.cn/docs/legals/terms-of-service)
- [SiliconFlow 隐私政策（更新日期 2026-06-25）](https://api-docs.siliconflow.cn/docs/legals/privacy-policy)

公开条款可能变更，接入内部资料前必须重新审查并保存当时版本或合同编号。当前
`public-data-exception` 只允许不含个人信息和商业秘密的公开材料，不能自动升级为内部数据
批准。

## 删除请求流程

1. 数据负责人确认租户、知识库、文档、会话或评测集的精确 ID，以及是否存在法律保留。
2. 先停止相关写入与运行任务；文档使用应用删除任务，禁止直接删除 PostgreSQL 行而遗留向量。
3. 核对 Worker 任务成功、原文件不存在、分块为零、Milvus 无该文档活动版本。
4. 归档知识库或会话，并在审计日志和审批工单中记录结果。
5. 如外部模型供应商承诺提供删除请求渠道，按合同执行并保存确认编号，不在仓库记录人员隐私。
